## Invocation patterns (this box)

- WSL from Windows: `wsl -e bash -lc '<cmd>'` — Git Bash is NOT WSL; `~` paths only exist inside wsl.
- RetroCore builds: single project + `/p:UseSharedCompilation=false` (full-solution builds OOM).
  ALWAYS check build exit code before trusting test output; finish with `dotnet build-server shutdown`.
- nd500x compile run: `ND500X_FRAMELOG=1 ./build/bin/nd500x --monitor --sintran-root <root> --user GUEST --script <file>`.
- Radix: microcode addresses are OCTAL (`025522` = 0x2B52). File offset in DATA = octal_address * 16.
